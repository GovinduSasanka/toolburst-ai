repo-shorts

The private production tool behind the ToolBurst AI YouTube channel

repo-shorts is a personal tool that makes short vertical videos about free, open-source AI tools for the ToolBurst AI YouTube channel. It runs on one computer owned by the channel owner and is not offered to anyone else.

It uses the YouTube API Services to do three things, for the owner's own channel only:

  • upload the channel's finished videos, with their title, description and thumbnail;
  • schedule when those videos become public;
  • read the channel's own analytics, so future videos can be improved.

It never accesses any other person's account or channel.

repo-shorts uses the YouTube API Services (the YouTube Data API and the YouTube Analytics API). Its use is governed by the YouTube Terms of Service and the Google Privacy Policy.
